# AdminExpress Login

## Descripción

AdminExpress Login es un proyecto de interfaz web que simula una pantalla de inicio de sesión moderna y adaptable a diferentes dispositivos. Su diseño está inspirado en una interfaz administrativa con una combinación de colores azul y blanco.

El proyecto fue desarrollado como una práctica académica utilizando tecnologías frontend.

## Tecnologías utilizadas

* **HTML5:** estructura de la página web.
* **CSS3:** diseño visual, colores, distribución y adaptación a dispositivos móviles.
* **JavaScript:** interactividad, validación del formulario y visualización de la contraseña.

## Características

* Diseño moderno y minimalista.
* Interfaz adaptable a computadoras, tabletas y teléfonos móviles.
* Campos para correo electrónico y contraseña.
* Validación de campos obligatorios.
* Validación básica del formato del correo electrónico.
* Función para mostrar u ocultar la contraseña.
* Mensajes informativos al enviar el formulario.
* Enlaces de demostración para recuperar la contraseña y registrarse.

## Instalación y ejecución

No es necesario instalar dependencias ni utilizar un servidor backend.

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/TU-USUARIO/adminexpress-login.git
   ```

2. Entrar en la carpeta del proyecto:

   ```bash
   cd adminexpress-login
   ```

3. Abrir la carpeta en Visual Studio Code.

4. Abrir el archivo `index.html` directamente en el navegador o utilizar la extensión **Live Server** para ejecutar el proyecto.

## Funcionamiento

El usuario puede introducir un correo electrónico y una contraseña, visualizar u ocultar la contraseña y enviar el formulario para comprobar las validaciones implementadas.

Los enlaces de recuperación de contraseña y registro muestran mensajes informativos de demostración.

**Nota:** Este proyecto implementa únicamente una simulación frontend. No dispone de autenticación real, conexión a una base de datos ni un backend que gestione usuarios.

## Objetivo académico

Practicar los fundamentos del desarrollo web frontend mediante la creación de una interfaz de inicio de sesión, aplicando HTML, CSS y JavaScript.
